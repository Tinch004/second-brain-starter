## Regla de nombres
Cada archivo de proyecto se llama `<proyecto>-status.md` / `-todos.md` / `-decisions.md` / `-context.md` (nunca `_status.md` a secas) — único en todo el vault, se identifica solo en el grafo y en el buscador. Cada índice de carpeta se llama `<Carpeta>-index.md`, nunca `README.md` a secas — mismo motivo. Cómo armar un proyecto nuevo: skill [[SKILL|update-project-memory]].
