Agent Skills reales instaladas en esta máquina (Claude Code + Codex, mirroreadas entre `~/.agents/skills/` y `~/.codex/skills/`). Agrupadas por dominio en subcarpetas (`02-Skills/<grupo>/`), no en lista plana — agrupar es lo que mantiene esto navegable a medida que se agreguen más.

## Grupos
_(vacío — se crea el primer grupo la primera vez que se instala una skill real, ej. `02-Skills/general/` para prácticas de desarrollo, o `02-Skills/<tu-stack>/` para lo específico de tu lenguaje/framework)_

## Regla para skills nuevas
Cuando se instale una skill nueva, no se agrega suelta acá arriba: se decide a qué grupo pertenece o si hace falta un grupo nuevo, y se agrega la nota dentro de esa subcarpeta, linkeada desde el índice del grupo. El nombre del archivo de índice de un grupo sigue el patrón `Skills-<Grupo>-index.md` — nunca `README.md`, para que sea un nombre único en el grafo de todo el vault, no repetido carpeta por carpeta.
